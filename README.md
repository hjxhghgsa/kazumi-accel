# KazumiAccel —— Kazumi 本地加速代理

对标 LibreTV「加速 / 零缓存 / 随便拖动进度条」体验的 **本地** 加速代理，专为 Kazumi 设计。
仅监听 `127.0.0.1`，不对外暴露，所有缓冲只在内存中完成。

---

## 一、项目要解决的问题

Kazumi 播放部分视频源时：源不支持 `Range` 导致进度条拖不动、反复白屏；
播放器缓冲会写盘产生大缓存文件。本项目提供一个**纯本地、零缓存**的代理层：

- 对支持 `Range` 的源：直接转发（高效、可拖动）。
- 对不支持 `Range` 的源：整段缓冲到**内存**后再按客户端 `Range` 切片返回，于是进度条任意拖拽都能即时定位。
- 全程不写任何磁盘缓存文件。

> 说明：本工具只做本地流量中转与内存缓冲，**不含任何抓取规则、不内置视频源**。视频源来自你自己的 Kazumi 配置。

---

## 二、主要功能

| 功能 | 说明 |
| --- | --- |
| 重写模式 | `GET /p?u=<URL编码后的视频地址>`，把目标视频拉进内存缓冲（零磁盘缓存），按 `Range` 切片返回 |
| 透明代理模式 | 把 `http://127.0.0.1:8899` 填进 Kazumi「全局代理」，普通请求转发、`CONNECT` 隧道透传 |
| 零缓存 | 所有缓冲只在内存，绝不写盘；超过 1.5GB 自动退化为透传以防 OOM |
| 本机隔离 | 仅监听 `127.0.0.1:8899`，不对外网暴露 |

## 三、安装方法

### 1. 环境要求

- 已安装 [Node.js](https://nodejs.org/)（建议 18+，含 `node` 命令）。
- 已安装 Kazumi 客户端。

### 2. 获取代码

```bash
git clone https://github.com/hjxhghgsa/kazumi-accel.git
cd kazumi-accel
```

### 3. 启动代理

```bash
node server.js
# 默认监听 http://127.0.0.1:8899
```

也可双击 `KazumiAccel-Proxy.bat`（脚本会自动切到自身所在目录后启动）。

## 四、使用示例

### 重写模式（手动拼地址）

把视频地址做 URL 编码后拼成：

```text
http://127.0.0.1:8899/p?u=<编码后的视频地址>
```

在浏览器 / 下载工具 / 播放器里打开这个地址即可走本代理（内存缓冲 + 任意 seek）。

### 全局代理模式（接进 Kazumi）

1. 先启动 `server.js`（或 `KazumiAccel-Proxy.bat`）。
2. 打开 Kazumi 设置 → 把「全局代理」填为 `http://127.0.0.1:8899`。

> 备注：Kazumi 播放走 libmpv，https 走 `CONNECT` 隧道时本代理只做透传。
> 想让 Kazumi 播放**真正变快、零盘缓存、拖动流畅**，关键是 MPV 配置：
> 把 `mpv.conf` 放到你的 Kazumi 安装目录下的 `mpv-config\`（或 `%APPDATA%\mpv\mpv.conf`），
> 若版本不读文件配置，可在 Kazumi 设置 → 播放器 → 自定义 MPV 参数里原样粘贴。

### 验证

- 拖进度条：播一个视频，前后拖动应即时定位、不卡白屏。
- 零缓存：播放期间查看 Kazumi 安装目录与临时目录，不应出现新的大缓存文件。
